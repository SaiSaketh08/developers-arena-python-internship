# Personal Information Manager

## Project Description

This is a beginner-level Python project created as part of Week 1 of The Developers Arena Python Internship.

The Personal Information Manager stores basic personal information, asks the user for additional information, validates the input, and displays everything in a clear format.

## What I Learned

1. Variables and data types
2. Input and output using input() and print()
3. String formatting using f-strings
4. Basic input validation
5. While loops
6. String methods such as strip()
7. Basic arithmetic operations
8. Writing comments in Python

## Features

- Stores name, age, city, and hobby
- Takes favorite food from the user
- Takes favorite color from the user
- Validates empty inputs
- Calculates age in months
- Displays information in a formatted output
- Includes welcome and goodbye messages
