# Student Grade Calculator

## Project Description

The Student Grade Calculator is a Python-based program developed as part of Week 2 of The Developers Arena Python Internship.

The program collects student names and marks for four subjects, validates the input, calculates the average marks, assigns a grade, provides a personalized comment, and displays class statistics.

The project was created to practice control flow, data structures, loops, functions, and error handling in Python.

## What I Learned

1. Conditional Logic: Using if, elif, and else for decision making
2. Lists: Storing and managing student marks and results
3. For Loops: Processing multiple students
4. While Loops: Repeating input until valid data is entered
5. Error Handling: Using try-except to handle invalid inputs
6. Functions: Creating reusable functions for grade calculation and input validation
7. String Formatting: Creating a clean and organized results table
8. Statistics: Calculating class average, highest average, and lowest average

## Features

- Processes multiple students
- Accepts marks for English, Science, Math, and History
- Validates marks between 0 and 100
- Handles invalid numerical input
- Prevents empty student names
- Calculates individual student averages
- Assigns grades based on average marks
- Provides personalized comments
- Stores student information using lists
- Calculates class average
- Finds highest and lowest student averages
- Displays results in a formatted table
- Uses functions for reusable operations

## Grading System

| Average | Grade | Comment |
|---|---|---|
| 90-100 | A | Excellent! Keep up the great work! |
| 80-89 | B | Very Good! You are doing well. |
| 70-79 | C | Good. Room for improvement. |
| 60-69 | D | Needs Improvement. Please study more. |
| 0-59 | F | Failed. Please seek help from your teacher. |
