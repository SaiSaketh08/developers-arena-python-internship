# The Developers Arena - Python Internship

This repository contains the projects and tasks completed during my Python Internship at The Developers Arena.

## Projects

### Week 1 - Personal Information Manager

A beginner-level Python project that stores and manages personal information using variables, user input, and basic validation.

**Technologies:**
- Python
- Variables and Data Types
- Input and Output
- Basic Validation

### Week 2 - Student Grade Calculator

A Python-based grade calculator that processes multiple students, validates marks, calculates averages and grades, provides personalized comments, and generates class statistics.

**Technologies:**
- Python
- Conditional Statements
- Lists
- For Loops
- While Loops
- Functions
- Try-Except Error Handling
- Input Validation

**Features:**
- Processes multiple students
- Validates marks between 0 and 100
- Calculates student averages
- Assigns grades from A to F
- Provides personalized comments
- Calculates class average
- Finds highest and lowest averages
- Displays results in a formatted table
